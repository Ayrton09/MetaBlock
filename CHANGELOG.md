# Changelog

## [1.0.0] - 2026-10-07

Initial release.

### Added
- Blocks Metamod's `meta` for players, ahead of Metamod's own handler.
- Blocks `css_plugins` and `css` from the console and from chat.
- `BlockedCommands`: any other console command can be blocked the same way.
- `AllowAdmins` and `AdminFlag`: admins can be let through, or everyone blocked.
- `BlockMessage`: the text players get, or nothing.
